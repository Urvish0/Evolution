# Prose Humanizer Skill

Edit and draft for reader trust. Ground every sentence in real implementation details and evidence.

## Guidelines

1. **Evidence First**: Only make claims that exist in the codebase, tests, or verified benchmarks.
2. **Eliminate Promotional Varnish**: Strip words like "revolutionary", "game-changing", "world-class", "seamless". State the technical specifications directly.
3. **Natural Cadence**: Avoid formulaic bullet structures, rhetorical questions ("The result?"), and staged pauses ("Here's the thing:").
4. **Zero Emoji Clutter**: Do not prefix bullet points with emojis. Keep formatting clean and professional.
